# penpot-self-host

Self host [Penpot](https://penpot.app) — the open source design tool.

## Why Penpot instead of Excalidraw

Penpot is essentially an open source Figma: mock up UI and diagram technical stuff, all in one place. So it does anything I need, and it has MCP built in. See [docs/connect-mcp.md](docs/connect-mcp.md).
